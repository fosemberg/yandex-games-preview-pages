# yandex-games-preview-pages

Опубликованное превью каталога Яндекс Игр для игр fosemberg.

**Смотреть:** <https://fosemberg.github.io/yandex-games-preview-pages/>

Это макет, а не страница Яндекс Игр: вёрстка повторяет настоящие страницы
платформы, но оценки и счётчики в нём — заглушки, о чём написано полосой
сверху на каждой странице.

## Как это устроено

Папка `docs/` — **артефакт сборки**, её не правят руками: она целиком
пересобирается из репозитория
[`yandex-games-preview`](https://github.com/fosemberg/yandex-games-preview).

```bash
cd ../yandex-games-preview
npm install
npm run build          # → ../yandex-games-preview-pages/docs
```

Дальше здесь закоммитить `docs/` и запушить. GitHub Pages настроен на ветку с
папкой `docs`.

Все правки — текстов, картинок, вёрстки — вносятся в `yandex-games-preview`.

## Что внутри docs

```
index.html                 главная каталога — девять игр
app/<игра>/index.html      страница игры: кадр, оценки, скриншоты,
                           «Об игре», «Как играть», теги
play/<игра>/index.html     игра в рамке под шапкой платформы
en/…                       то же самое по-английски
assets/                    один CSS и один JS
media/<игра>/              иконка, обложки, скриншоты
.nojekyll                  чтобы Pages отдавал файлы как есть
```
